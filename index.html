Demostración interactiva

Ubicación y estado visual de recursos

Visualiza la ubicación de un producto, material o recurso mediante un indicador sencillo dentro de un layout digital.

Un foquito verde puede representar un recurso disponible y uno rojo un recurso que requiere atención.

El layout es ilustrativo. Puede adaptarse a una tienda, ferretería, almacén, oficina o área de producción.

Esta demostración es local y utiliza estados ficticios. La actualización en tiempo real requiere integrar ATZE con los sistemas o fuentes de datos correspondientes.
