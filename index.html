Ubicación visual de componentes en planta

ATZE permite identificar visualmente dónde se encuentra un componente dentro de las instalaciones. Al buscar un componente, un foco se enciende en el layout de la planta para señalar su ubicación.

  • Busca el componente que necesitas localizar.
  • Visualiza el layout de la planta.
  • Identifica la ubicación del componente mediante un foco que se ilumina en el plano.
  • Facilita la orientación del personal dentro de las instalaciones.

Ejemplo del layout de planta utilizado para identificar la ubicación de un componente.
